# AGENTS.md

## Vision
SQR (pronounced "Square") is a Python-based AI travel companion combining conversational AI with a purpose-built UI. Unlike general-purpose agents, SQR focuses on one domain: helping users plan, manage, and experience trips.

Core capabilities:
- Capture travel preferences and constraints.
- Plan destinations, stops, and attractions.
- Maintain structured, editable itineraries.
- Generate daily travel briefings based on the current itinerary.

**Principle:** Focused functionality, structured data, intuitive UX, and human control.

## Project Objective
Developing an MVP that demonstrates SQR's core value through a coherent, usable travel-planning workflow.

SQR is also a software engineering learning project. Practical application and critical evaluation of engineering concepts are as important as the resulting product.

### Learning Context
The project covers these module topics:

- **DVC:** Distributed Version Control Systems
- **CID:** Continuous Integration / Continuous Delivery
- **UML:** Unified Modeling Language
- **AJV:** Advanced Java
- **MET:** Software and Architecture Metrics
- **CCD:** Clean Code Development
- **BUI:** Advanced Build Management
- **AOP:** Aspect-Oriented Programming
- **MIC:** Microservices
- **FPR:** Functional Programming
- **DSL:** External and Internal Domain-Specific Languages
- **SML:** Software Engineering for Machine Learning

The agent should reference these concepts when relevant, involve developers in related decisions, and discuss significant new developments. It should encourage understanding and critical evaluation rather than make consequential decisions without developer participation.

### Engineering Principles

Despite the MVP scope, prioritize clean code, maintainability, testing, and established engineering practices over shortcuts. Prefer simple, well-founded solutions over unnecessary complexity, but do not sacrifice sound engineering merely to deliver features faster. Use the project as an opportunity to teach the developers in those learning topics to understand the rationale and trade-offs behind technical decisions.
